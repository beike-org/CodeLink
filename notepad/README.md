# Notepad模块

## 简介

Notepad模块是CodeLink插件的重要组件之一，主要负责提供记事本编辑和管理功能。用户可以在使用chat/agent功能时，通过@notepad指令选择相应的记事本将其添加到对话的上下文中。该模块提供了记事本的创建、编辑、删除和管理功能，使用户能够方便地管理和使用文本内容。

## 功能特性

- 记事本管理
    - 创建新的记事本文件
    - 编辑现有记事本内容
    - 删除不需要的记事本
- 记事本集成
    - 通过@notepad指令在对话中引用记事本内容
    - 记事本内容作为上下文参与AI对话
- 文件存储
    - 记事本以Markdown格式(.md)存储
    - 文件保存在项目的.idea/notepad目录下

## 核心组件

### 1. UI组件

- NotepadPanel: 记事本面板，提供记事本的UI界面和基本操作
- NotepadToolWindowFactory: 工具窗口工厂，创建记事本工具窗口
- NotepadToolWindowCondition: 工具窗口条件类，控制工具窗口的显示条件

### 2. 处理程序

- NotepadKeCopilotPanelHandler: 记事本面板处理程序，管理WTP和PTW处理程序
- NotepadFileListWTPHandler: 记事本文件列表处理程序，获取记事本文件列表
- AddNotepadWTPHandler: 添加记事本处理程序，处理新建记事本的操作

## 实现细节

### 文件存储

记事本文件以Markdown格式存储在项目的.idea/notepad目录下。每个记事本文件都是一个独立的.md文件，可以通过IDE的编辑器直接打开和编辑。

### 用户界面

记事本模块提供了一个简洁的表格界面，显示所有可用的记事本文件。用户可以通过界面上的按钮执行以下操作：

- 点击"新建记事本"按钮创建新的记事本
- 点击记事本行中的"编辑"按钮打开记事本进行编辑
- 点击记事本行中的"删除"按钮删除记事本

### Webview通信

记事本模块通过以下处理程序与Webview进行通信：

- NotepadFileListWTPHandler: 处理获取记事本文件列表的请求
- AddNotepadWTPHandler: 处理添加记事本的请求

## 配置文件

Notepad模块使用以下配置文件：

- notepad.xml: 定义了keCopilotPanelHandler的实现

## 开发指南

### 扩展记事本功能

如需扩展记事本功能，可以考虑以下方向：

1. 增强编辑功能：
    - 在NotepadPanel中添加更多的编辑功能
    - 支持更多的文件格式

2. 改进用户界面：
    - 添加搜索和过滤功能
    - 提供更丰富的排序选项
    - 优化记事本列表的显示方式

3. 增强与AI对话的集成：
    - 提供更多的上下文控制选项
    - 支持部分内容引用

## 注意事项

- 记事本文件存储在项目目录下，与项目绑定
- 大文件处理时需注意内存使用
- 确保文件编码的正确处理
