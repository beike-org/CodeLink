# Agentic 模块

Agentic模块是CodeLink项目的核心基础模块，作为除common外的其他功能模块的基础设施，负责管理和协调IDE与外部代理进程之间的通信。该模块提供了一套完整的代理进程管理、通信、诊断和UI交互机制，为上层功能模块提供稳定可靠的服务支持。

## 主要功能

### 1. 代理进程管理

- 管理代理进程的完整生命周期（启动、监控、关闭）
- 自动端口分配和冲突处理机制
- 进程状态实时监控和异常自动恢复
- 支持多进程并行管理和资源隔离

### 2. Socket通信

- 基于NanoHTTPD的轻量级HTTP Socket服务器
- 支持IDE与代理进程间的双向实时通信
- 请求响应处理机制和超时控制
- 高效的缓存管理和连接池

### 3. 文件操作

- 高性能文件读写和内容处理
- 文件变更实时监听和事件通知
- 目录递归遍历和高级搜索
- 文件差异比较和合并

## 核心组件

### 1. SideCarAgentManager

- 代理进程的核心管理器，负责整个代理生态系统的协调
- 提供端口智能分配和进程生命周期全方位管理
- 实现进程状态实时监控和异常自动恢复机制
- 支持多种配置选项和扩展点

### 2. SideCarHttpSocketServer

- 基于NanoHTTPD实现的高性能HTTP服务器
- 处理IDE与代理进程间的双向通信
- 提供完整的HTTP接口支持和请求路由
- 实现高效的连接管理和请求分发

### 3. DiagnosticsProcessor

- 智能代码诊断引擎，支持多语言分析
- 提供丰富的诊断结果分析和问题分类
- 生成详细的错误报告和修复建议
- 支持实时诊断和批量处理


## 技术栈

- Java (IntelliJ Platform SDK)
- NanoHTTPD (轻量级HTTP服务器)
- WebSocket (实时通信)
- JSON/FastJSON (数据序列化)
- Concurrent Utilities (并发处理)

## 配置项

- 默认代理端口: 42424 (支持自动递增)
- 默认Socket端口: 41100 (支持自动递增)
- 端口自动分配范围: 当前端口 ~ 当前端口+1000
- 进程超时设置: 可配置
- 缓存过期时间: 可配置

## 依赖关系

- 作为基础模块，依赖common模块提供的基础设施
- 为其他功能模块提供代理进程管理和通信服务


## 扩展机制

- 提供插件化的请求处理器注册机制
- 允许扩展WebView命令处理器
- 提供事件监听和通知机制
